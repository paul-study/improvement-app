# LifeLift - Personal Growth Hub

A modern, interactive static website for self-help and life improvement. Track your goals, build habits, practice exercises, and celebrate achievements all in one place.

## Features

### 🗣️ Positive Self-Talk
- Daily affirmations to rewire your mindset
- Create and save custom affirmations
- Random affirmation generator

### 💪 Daily Motivation
- Inspiring quotes from notable figures
- Fresh motivation with each click
- Curated collection of empowering messages

### 🧘 Exercises & Activities
- **Mindfulness Meditation** - 5-minute guided practice
- **Gratitude Journaling** - Reflect and appreciate
- **Quick Workouts** - Energize your body
- **Focus Sessions** - Pomodoro technique
- **Breathing Exercises** - Box breathing for stress relief
- **Visualization** - Picture your ideal future

### 🎯 Goal Setting
- Set goals across multiple categories (Health, Career, Learning, etc.)
- Track deadlines and progress
- Mark goals as complete
- Visual category badges

### 🏆 Achievements & Milestones
- Log daily wins and accomplishments
- Track statistics (goals set, completed, exercises done)
- Celebrate your progress
- Streak counter for consistency

### 📚 Skills Development
- Track skills you're developing
- Set proficiency levels (Beginner, Intermediate, Advanced)
- Log practice sessions
- Visual progress bars
- Suggested skills to explore

### 🌱 Habit Building
- 30-day habit challenges
- Visual calendar tracking
- Check off completed days
- Progress percentages
- Tips for successful habit formation

### 📖 Resources
- Curated reading list
- Recommended podcasts
- Helpful tools
- Daily practice suggestions

## Technology

- **Pure HTML5** - Semantic structure
- **Modern CSS3** - Responsive design with CSS Grid and Flexbox
- **Vanilla JavaScript** - No dependencies, lightweight and fast
- **LocalStorage** - Persistent data storage in the browser

## Design Principles

- ✅ Clean, modern interface
- ✅ Easy to read typography
- ✅ Intuitive navigation
- ✅ Mobile responsive
- ✅ Accessible color palette (no purple!)
- ✅ Smooth animations and transitions

## Color Palette

- **Primary Blue**: #2563eb - Trust and stability
- **Secondary Green**: #16a34a - Growth and renewal
- **Accent Orange**: #f59e0b - Energy and enthusiasm
- **Dark**: #1e293b - Professional and grounded
- **Light**: #f8fafc - Clean and spacious

## Getting Started

Simply open `index.html` in your web browser. No build process or dependencies required!

All your data is stored locally in your browser using LocalStorage, so your progress persists between sessions.

## Browser Compatibility

Works in all modern browsers:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Opera (latest)
